# 🗓 응모 도우미 (안드로이드 · 반자동)

매일 열리는 이벤트(쇼핑몰·포털/앱테크·금융/증권사 출석·퀴즈·폼·선착순)를 **빠짐없이** 챙기는 폰 앱입니다.

- 아침에 "오늘 응모할 이벤트 N건" 알림 → 앱에서 [응모하기] → 사이트가 앱 안에서 열림(로그인 유지)
- **최종 제출·캡차·약관 동의는 내가 직접** 누릅니다 (계정 안전 · 사이트 약관 준수)
- 캡차 자동 풀이 · 여러 계정 · 초 단위 연타 · 자동 댓글 기능은 **만들지 않습니다**
- 이벤트 목록·기록은 **폰 안에만** 저장

## 설치 (안드로이드)
1. 폰 크롬에서 이 저장소의 **Releases → `event-helper-latest` → `event-helper.apk`** 내려받기
2. "출처를 알 수 없는 앱" 허용 → 설치 (Play 스토어 앱이 아니라서 한 번 묻습니다)
3. 처음 실행 시 **알림 허용**

## 진행 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 목록·아침 알림·선착순 오픈 3분 전 알림·앱 안 브라우저·정답 자동 복사·결과 기록 | ✅ |
| 2 | 자동 보조 엔진 (팝업 닫기·입력·버튼 찾기 → 제출 직전 멈춤, 결과 자동 판정) | 예정 |
| 3 | 레시피 만들기 (요소 톡 선택, 유형별 템플릿, 프로필 암호화 저장) | 예정 |
| 4 | Gmail 알림 (실패 즉시 · 저녁 요약, Apps Script 중계) | 예정 |
| 5 | 로그 내보내기, 서명키 정식화, 마무리 | 예정 |

## 결과 코드
`SUCCESS`(성공) · `ALREADY_DONE`(이미 참여) · `CLOSED`(마감) · `USER_SKIPPED`(건너뜀) ·
`NETWORK_ERROR` · `TIMEOUT`(30초) · `FAILED` — 2단계부터 `LOGIN_REQUIRED` · `CAPTCHA` · `POPUP_BLOCKED` · `SELECTOR_NOT_FOUND` 자동 판정

## 알아둘 제한
- 일부 이벤트는 **앱 전용**(증권사·카드사 앱 안)이라 앱 안 브라우저로 못 엽니다 → 앱 주소(intent://, 앱 스킴)를 넣으면 그 앱을 바로 엽니다.
- 구글 계정 로그인은 앱 안 브라우저(WebView)에서 구글 정책상 막힙니다. 네이버·카카오 등은 사이트마다 다를 수 있어 실제 폰 확인이 필요합니다.
- 알림은 안드로이드 절전 때문에 몇 분 늦을 수 있습니다 (초 단위 정확도 아님).
- `android/keystore/debug.keystore` 는 업데이트 설치 때 데이터가 지워지지 않도록 **고정한 개인용 디버그 서명키**입니다(공개된 기본 비밀번호). 5단계에서 비공개 키로 바꾸는 방법을 안내합니다.

## 개발
- 빌드: GitHub Actions(`.github/workflows/event-helper-apk.yml`)가 푸시 때마다 APK를 만들어 Release에 올립니다.
- 화면 미리보기: `android/app/src/main/assets/ui/index.html` 을 PC 브라우저로 열면 가짜 저장소로 동작합니다.
