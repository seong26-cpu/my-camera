# 🗓 응모 도우미 (안드로이드 · 반자동)

매일 열리는 이벤트(쇼핑몰·포털/앱테크·금융/증권사 출석·퀴즈·폼·선착순)를 **빠짐없이** 챙기는 폰 앱입니다.

- 아침에 "오늘 응모할 이벤트 N건" 알림 → 앱에서 [응모하기] → 사이트가 앱 안에서 열림(로그인 유지)
- **최종 제출·캡차·약관 동의는 내가 직접** 누릅니다 (계정 안전 · 사이트 약관 준수)
- 캡차 자동 풀이 · 여러 계정 · 초 단위 연타 · 자동 댓글 기능은 **만들지 않습니다**
- 이벤트 목록·기록은 **폰 안에만** 저장

## 설치 (안드로이드)
1. 폰 크롬에서 이 저장소의 **Releases → `event-helper-latest` → `event-helper.apk`** 내려받기
2. "출처를 알 수 없는 앱" 허용 → 설치 (Play 스토어 앱이 아니라서 한 번 묻습니다)
3. 처음 실행 시 **알림 허용**

## 진행 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 목록·아침 알림·선착순 오픈 3분 전 알림·앱 안 브라우저·정답 자동 복사·결과 기록 | ✅ |
| 2 | 자동 보조 엔진 (팝업 닫기·입력·버튼 강조 → 직접 누름, 결과 자동 판정) + 추천 이벤트 100곳 | ✅ |
| 3 | 🎯 버튼 톡 지정(참여 버튼·메뉴), 프로필 암호화 저장 → 폼 빈 칸 자동 입력 | ✅ |
| 4 | 📧 Gmail 알림: 실패 즉시 + 저녁 하루 요약 (내 Apps Script → 나에게만) | ✅ |
| 5 | 📤 기록 CSV · 💾 전체 백업/복원 · 🔑 비공개 서명키 지원 · 빌드 전 자동 시험 | ✅ |

## 추천 이벤트 100곳
- [🗂 이벤트] 탭 → **⭐ 추천 이벤트 불러오기** → 원하는 곳만 **켜기**
- 2026-11-24 웹 검색 결과에 실제로 나온 공식 주소만 넣었습니다 (`tools/build_presets.py`). 이벤트는 자주 끝나므로 **진행 여부는 직접 확인**하세요.
- 🔒 **바로가기만**: 이벤트 유의사항에 '비정상적 방법·반복 참여 프로그램 금지' 문구가 확인된 곳(G마켓·삼성닷컴·야놀자 NOL·하나은행). 자동 보조를 켤 수 없습니다.
- **약관 미확인**: 나머지 사이트. 직접 약관을 읽고 금지 조항이 없을 때만 체크 → 자동 보조가 켜짐.

## 자동 보조가 하는 일 / 안 하는 일
| 한다 | 안 한다 |
|---|---|
| 광고 팝업의 '닫기·오늘 하루 보지 않기' 누르기 (처음 3초만) | 참여·응모·제출 버튼 자동 클릭 |
| 퀴즈 정답 칸에 미리 넣은 정답 입력 | 캡차 풀기, 약관 동의 체크 |
| 참여 버튼 찾아 빨간 테두리로 강조 | 반복 연타, 여러 계정, 봇 탐지 우회 |
| 이벤트 모음에서 '출석' 메뉴로 한 번 이동 | 사용자 몰래 백그라운드 실행 |
| 결과 문구(알림창·화면)로 성공/이미 참여/마감 자동 기록 | |

## 🎯 버튼 지정 · 👤 프로필 (3단계)
- **버튼 지정**: 응모 화면 아래 [🎯 버튼 지정] → '참여 버튼' 또는 '들어갈 메뉴' 선택 → 사이트에서 그 버튼을 톡.
  그 톡은 사이트에 전달되지 않고(눌리지 않음) 위치·글자만 저장 → 다음부터 그 버튼을 강조. 사이트가 바뀌어 위치가 달라지면 글자로 다시 찾음.
- **프로필**: 설정 탭에 이름·휴대폰·이메일·생년월일 → 안드로이드 키 저장소(AndroidKeyStore) 키로 AES-GCM 암호화해 폰에만 저장.
  '폼 입력' 유형 + 약관 확인한 사이트의 **빈 칸에만** 입력. 아이디·검색칸·나뉜 번호칸(4자리)·**개인정보 동의 체크는 건드리지 않음**.

시험: `node event-helper/test/mailer.test.js` (Apps Script 8개) · `node event-helper/test/engine.test.js` — 가짜 이벤트 페이지 11종, 33개 항목 (자동 제출 0회 확인 포함)

## 📧 Gmail 알림 설치 (4단계, 약 5분)
1. [script.google.com](https://script.google.com) → 새 프로젝트 → `apps-script/Mailer.gs` 내용 붙여넣기 → 저장
2. 함수 `setup` 선택 → ▶실행 → 권한 허용 → 로그의 **APP_TOKEN** 복사 (Gmail에 '설치 완료' 메일 오면 정상)
3. 배포 → 새 배포 → **웹 앱** → 실행: **나** / 액세스: **모든 사용자** → URL(`…/exec`) 복사
4. 앱 ⚙ 설정 → Gmail 알림에 URL·비밀번호 → [설정 저장] → [📧 연결 시험]

- 받는 사람은 스크립트 주인(나)으로 **고정** — 앱이나 다른 사람이 주소를 바꿀 수 없음
- 실패 즉시 메일: `실패·네트워크 오류·시간 초과·로그인 필요·캡차·팝업 방해·버튼 못 찾음` 기록 시
- 저녁 요약(기본 21:00): 완료 / 실패 기록 / 아직 안 한 이벤트
- 하루 최대 20통 (폭주 방지). 인터넷이 끊겨 있으면 연결될 때 보내고, 일시 오류는 최대 3번 다시 시도
- 메일에는 이벤트 이름·결과만 들어가고 **프로필(이름·연락처)은 들어가지 않음**

## 결과 코드

`NETWORK_ERROR`(자동 재시도 1회) · `TIMEOUT`(30초) · `FAILED` · `LOGIN_REQUIRED` · `CAPTCHA` · `POPUP_BLOCKED` · `SELECTOR_NOT_FOUND`(사이트 개편)

## 알아둘 제한
- 일부 이벤트는 **앱 전용**(증권사·카드사 앱 안)이라 앱 안 브라우저로 못 엽니다 → 앱 주소(intent://, 앱 스킴)를 넣으면 그 앱을 바로 엽니다.
- 구글 계정 로그인은 앱 안 브라우저(WebView)에서 구글 정책상 막힙니다. 네이버·카카오 등은 사이트마다 다를 수 있어 실제 폰 확인이 필요합니다.
- 알림은 안드로이드 절전 때문에 몇 분 늦을 수 있습니다 (초 단위 정확도 아님).
- `android/keystore/debug.keystore` 는 업데이트 때 데이터가 지워지지 않도록 **고정한 개인용 디버그 서명키**입니다(공개된 기본 비밀번호). 다른 곳에서 받은 '응모 도우미' APK는 설치하지 마세요. 더 안전하게 하려면 아래 🔑 비공개 키로 바꾸세요.

## 📱 앱 전용 이벤트 · 👥 가입 줄이기 (1.2)
- **앱 연결**: 응모 화면 [⋯ 더보기 → 📱 앱으로 열기] → 설치된 쇼핑몰 앱(또는 🌐 기본 브라우저) 선택 → 기억
  → 다음부터 [앱으로 ▶]가 그 앱을 바로 실행 (그 앱이 이벤트 주소를 열 수 있으면 이벤트 화면으로)
- **경로 메모**: 이벤트 수정 → '앱 안 경로 메모'(예: 마이 → 출석체크) → 앱을 열 때 알림에 표시
- **알림에서 결과 기록**: 다른 앱에 있는 동안 알림의 [✅ 성공] [🔁 이미 참여] [⚠ 실패] → 돌아오지 않고 기록
- **구글 로그인 자동 전환**: 앱 안 브라우저에서 구글 로그인 화면(accounts.google.com)이 나오면 기본 브라우저로 넘기고 다음부터 브라우저로 열기
  (구글이 2021-09-30부터 앱 내장 WebView 로그인을 차단 — [Google 개발자 블로그](https://developers.googleblog.com/2021/06/upcoming-security-changes-to-googles-oauth-2.0-authorization-endpoint.html))
- **👥 통합회원 필터**: 이벤트 탭 분야에서 'CJ ONE 계열'(5곳)·'롯데 L.POINT 계열'(8곳) → 가입 1번으로 여러 곳
- 하지 않는 것: 다른 앱 안의 버튼 대신 누르기(접근성 권한 자동 조작), 회원가입·본인인증 대행

## 📤 기록 CSV · 💾 백업/복원 (5단계)
- **📜 기록 탭 → 📤 CSV 내보내기**: 엑셀에서 한글이 깨지지 않게 저장. 사이트 문구가 `=`, `+` 등으로 시작하면 엑셀 수식으로 실행되지 않게 앞에 `'`를 붙임
- **⚙ 설정 → 💾 전체 백업 파일 만들기**: 이벤트·기록·설정을 한 파일로 → 드라이브나 메일에 보관
  - **메일 비밀번호와 프로필은 보안상 빠집니다** (복원 후 다시 입력)
- **📂 백업 파일 불러오기**: 새 폰이나 다시 설치한 뒤 복원. 형식 검사 후 확인을 받고 바꿉니다

## 🔑 비공개 서명키로 바꾸기 (선택)
> ⚠ 서명키가 바뀌면 안드로이드가 '다른 앱'으로 봐서 **한 번은 지우고 새로 설치**해야 합니다. 꼭 **💾 백업부터** 하세요.

1. PC(자바 설치)에서: `keytool -genkeypair -v -keystore eh-release.jks -alias eventhelper -keyalg RSA -keysize 2048 -validity 10000`
2. 파일을 글자로 바꾸기
   - Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("eh-release.jks")) | Set-Clipboard`
   - Mac: `base64 -i eh-release.jks | pbcopy`
3. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret 4개
   - `EH_KEYSTORE_BASE64`(2번 글자) · `EH_KEYSTORE_PASSWORD` · `EH_KEY_ALIAS`(`eventhelper`) · `EH_KEY_PASSWORD`
4. Actions → event-helper APK → Run workflow → 새 APK 설치 → 💾 백업 불러오기
- `eh-release.jks`와 비밀번호는 잃어버리면 업데이트를 못 하니 안전한 곳에 보관하고, **채팅이나 저장소에 올리지 마세요.**
