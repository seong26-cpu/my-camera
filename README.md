# 📷 나의 카메라

사진 보정 · 물체 선택(추출·지우기·옮기기) · 글자 추출 · 인테리어 추천 · 일괄 처리 · 파일 변환을
**폰 브라우저 안에서, 무료로** 하는 앱웹(PWA)입니다. Claude 없이도 계속 동작합니다.

- 원본 사진은 절대 바꾸지 않습니다. 결과는 항상 새 파일로 저장합니다.
- 사진은 폰 밖으로 나가지 않습니다. (인테리어 "실제 사진" 검색어만 사진 검색 사이트로 감)
- PC가 서버가 되지 않습니다. GitHub Pages(무료)에서 열립니다.

> 🗓 같은 저장소의 다른 앱: [응모 도우미 (안드로이드, 반자동 이벤트 응모)](event-helper/README.md)

## 1. 설치 (클릭만)

1. 폰 크롬으로 `https://seong26-cpu.github.io/my-camera/` 열기
2. 처음 화면의 초록색 **[📲 설치]** 버튼 → **[설치]**
3. 끝. 와이파이에 연결되면 AI 모델은 앱이 알아서 내려받습니다.

- 인테리어 실제 사진: 키·가입 없이 자동 (Openverse의 CC0·퍼블릭 도메인 실사 사진)
- (선택·고급) Pexels 사진도 쓰고 싶을 때만 `apps-script/Code.gs` 연결 — 앱 도움말 참고

## 기능과 처리 방식

| 메뉴 | 하는 일 | 엔진 (모두 무료) |
|---|---|---|
| 보정 | 자동·수동 보정, 자르기·회전, 내 스타일 표(.cube) 만들기·입히기, 여러 장 한 번에 | 직접 구현 (편남 v8.0 방식 이식) |
| 물체 선택 | 톡 → 선택, ➕/➖·붓으로 다듬기, 투명 PNG 추출, 지우기, 옮기기(끌기·크기·회전) | MediaPipe Interactive Segmenter, LaMa |
| 글자 추출 | 한글·영어, 여러 장, 복사·TXT | Tesseract.js |
| 인테리어 | 색·밝기 분석, 스타일 추천, 예산 순서, 실제 사진 | 규칙 + CLIP(자동 준비) + Openverse 실사 사진 (Pexels 선택) |
| 일괄 처리 | 자동 보정·내 스타일·크기·형식·글자·이름 바꾸기 | 위와 동일 |
| 파일 변환 | JPG·PNG·WebP, 용량 줄이기, HEIC→JPG, 사진→PDF, PDF→사진 | pdf.js, jsPDF, heic2any |

AI 모델은 처음 쓸 때 한 번 내려받아 폰에 저장합니다 (물체 인식 / 고품질 채움 약 수십 MB / 스타일 판별 약 154MB / 한글 데이터 약 5MB).

## 검증한 것

- 내 스타일 표: 편남 v8.0 파이썬 원본과 같은 입력으로 비교 — 표 값 차이 0.0000005 이하, 입힌 결과 픽셀 차이 최대 1
- 브라우저 시험(모바일 화면): 보정·EXIF 유지·회전, 스타일 만들기, 일괄 처리, 형식 변환, PDF 만들기·쪼개기, 한글 OCR, 인테리어, 물체 추출·옮기기 흐름, 오프라인 실행
- 실제 물체 인식 모델·LaMa·CLIP 다운로드는 개발 환경 인터넷 제한으로 시험하지 못함 → 폰에서 첫 실행 때 확인 필요
